## 〇、信号约定与总览

### 0.1 信号约定

所有策略 `generate_signals(df)` 返回与行情 `df.index` 对齐的 `pd.Series`，取值如下：

| 信号值 | 含义 | 报告中显示 |
|:---:|---|---|
| `1` | 买入 | 买（绿色/红色加粗，视上下文） |
| `0` | 观望 | 观 |
| `-1` | 卖出 | 卖 |

> **强弱信号已合并**：原先的弱买 `+0.5` / 强买 `+1` 统一为「买」`+1`，弱卖 `-0.5` / 强卖 `-1` 统一为「卖」`-1`。
> 各策略的 `enhance`（`-gN`）仍控制**是否触发**该方向信号（过滤条件更严格、信号更少），但不再区分信号值大小。
> 回测中（fraction 模式）仓位水平 `in_position` 为 0~1 浮点数，按 `±1` 累加/递减并封顶：`in_position<1` 时买入、`>0` 时卖出。
>
> 质价融合策略会额外在 `signals.attrs` 中附加 `combined_score`（综合得分）、`z_score`（Z 分数）与 `stock_type`（标的类型）。
>
> **RSI 过滤已内置**：MA1030 / EMA1030 / MACD1226 / BOLL / MA310 / MA520 / EMA520 的买入条件统一附加
> `RSI < MIN_RSI_THRESHOLD`（且条件），卖出条件统一附加 `或 RSI > MAX_RSI_THRESHOLD`（RSI 优先取 `RSI14`，
> 缺失时用 `calc_rsi(df,14)` 现算）。阈值来自 `input/stock-quant.json`（见 0.4），因此独立的 RSI 策略已取消注册。
>
> **全局买入附加条件**：所有策略的买入信号（`>0`）统一附加「当日涨幅 < 9.9%」。若 `close.pct_change() >= 9.9%`，
> 该日买入信号被置为观望；卖出/观望信号不受影响。该过滤在信号生成后集中执行（`_filter_buy_on_big_gain`），
> 覆盖回测、扫描、对比、分析、单持仓轮动及次日预测等所有信号入口。
>
> **SAR 买入过滤（`SAR_CHECK`）**：`SAR_CHECK=1` 时，除 SAR 策略外的所有策略（含 PREV/复合策略等派生信号）
> 的买入信号统一附加「当日 `SAR < close`」；`SAR_CHECK=0` 时不检查 SAR。BOLL/SG/MACD 在策略内部同步该条件，
> 其余策略在信号生成后外部过滤，避免被过滤的买入影响持仓状态。
>
> **BOLL EMA60 买入过滤（`EMA60_CHECK`）**：`EMA60_CHECK=1` 时，BOLL 的买入信号附加
> 「当日 `EMA60 < close`」条件；`EMA60_CHECK=0` 时不检查 EMA60。
>
> **BOLL ADX 买入过滤（`ADX_CHECK`）**：`ADX_CHECK=1` 时，BOLL 的买入信号附加
> 「当日 `ADX > 20`」条件；`ADX_CHECK=0` 时不检查 ADX。
>
> **全局指数过滤（`INDEX_CHECK`）**：
> `0`=不检查；`1`=所有策略（含 SAR、PREV/复合策略等派生信号）买入需「上证指数收盘 > 上证指数 5 日均线」；
> `2`=买入需「上证指数收盘 > 上证指数 5 日均线 **或** 个股收盘 > 个股 5 日均线」。
> BOLL/SG/MACD 在策略内部同步该条件，其余策略在信号生成后外部过滤。
>
> **信号序号与 `--seqnum/-sn`（仅 BOLL 生效）**：买入信号序号表示「自上次卖出以来第几次买入信号」
> （首次为 1）。任何卖出信号（无论持仓还是空仓）都会重置计数；入场时刻本身也视为刚执行了一次卖出，
> 入场后的买入信号重新从 1 计数。`N=0` 表示不过滤；`N>0` 时仅保留第 N 次买入信号，其余买入按观望处理；
> 卖出信号不受影响、始终保留。**其它策略忽略该选项，始终按 `N=0` 处理。**
>
> **in_pos 同步**：BOLL / SG1 / SG2 / SG3 在 `generate_signals` 内部直接应用「当日涨幅 < 9.9%」
> 过滤（BOLL 还同步 `-sn`），`in_pos` 只在买入信号实际生效后置位。被过滤的买入不会被视为已入场，
> 因此不会抑制后续买入，也不会产生依赖未入场持仓的孤立卖出（例如 2026-07-21 涨幅超限被取消后，
> 不应再出现由该笔持仓推导出的 2026-10-12 回撤止损卖出）。BOLL 的序号按原始买入信号计数（包含被涨幅过滤的买入），
> 以便 `-sn 2` 能选中同一卖出周期内的第 2 个买入条件。
>
> **注意**：若一个「卖出→买入」区间内只有一个买入信号，`-sn N>1` 仍不会产生交易；只有存在多个买入条件时
> （如 000333 BOLL 的 2026-03-24 与 2026-03-31）才能正常触发。

### 0.3 数据来源（`--src`）

行情数据由 `DataFetcher` 获取，通过 `--src` 指定数据通道：

| `--src` | 取数方式 | 失败回退 |
|:---:|---|---|
| `sina`（默认） | 新浪 K 线 API（前/后复权用新浪复权因子） | Baostock → 东方财富 |
| `baostock` | Baostock（`adjustflag` 直接返回复权价） | 新浪 → 东方财富 |
| `eastmoney` | 东方财富 K 线 API（`fqt=1/2` 前/后复权） | 新浪 → Baostock |
| `db` | 仅 MySQL（严格模式） | 无（数据不完整/缺失 → 报警退出） |

- **网络源不再优先读 DB**：`sina` / `baostock` / `eastmoney` 只走对应网络通道，失败按上表回退，不会先读取数据库。
- **`--src db`**：只读 MySQL，要求「首条 ≤ start+5天 且 末条 ≥ end-1」（`start` 为实际取数起点，含 90 天预热）；不满足时抛出 `DataSourceError`，CLI 报警退出，不回退网络。
- `eastmoney` / `db` 不提供股票列表接口；`scan` / 随机抽样使用 `--src db` 时会直接报错。
- **回测 HTML 报告**在概要区显示本次实际使用的数据来源（如 `sina`、`db`；批量回测可能显示 `sina, baostock`）。
- 适用于 `analyze` / `scan` / `backtest` / `compare` / `indicators`；`strategy_rank_test.py` 亦支持 `--src` 并透传给 `backtest`。
- 数据获取起点 = 分析/回测 `start` 前推 90 自然日（`_ANALYSIS_WARMUP_DAYS`）以正确计算指标，计算后截断回 `start`。
- **股票列表同样遵守 `--src`**：`get_stock_list()` 首选源失败时自动切换备用源；sina 走行情中心分页，
  baostock 走最近交易日全市场快照。Baostock 不提供总市值，`--nolowcap`/市值排序在该源下不生效并给出警告。
- 实现见 `core/data_fetcher.py`（`set_primary_source` / `_get_a_stock_data` / `get_stock_list`），数据格式详见 `doc/data_structure.md`。

### 0.4 统一阈值配置（`input/stock-quant.json`）

阈值集中在 `thresholds` 节，策略未显式传参时自动读取（`core/thresholds.py`），**以配置文件当前值为准**：

| 配置项 | 代码回退默认 | 作用 |
|------|:---:|------|
| `MAX_DRAWDWON_THRESHOLD` | 15 | 最大回撤止损阈值（百分比）：买入后自最高收盘价回撤 ≥ 该值 → 卖出（**或**条件） |
| `MAX_RSI_THRESHOLD` | 85 | RSI 卖出阈值：`RSI > 该值` → 卖出（**或**条件） |
| `MIN_RSI_THRESHOLD` | 25 | RSI 买入阈值：`RSI < 该值` → 允许买入（**且**条件） |
| `PE_THRESHOLD` | 100 | `scan` 选股 PE 上限：`PE > 该值` 剔除（不参与策略信号） |
| `BOLL_SQUEEZE_SCALE` | 0.2 | BOLL 挤压判定比例因子：`bbw <= bbw_pctl × 该值` |
| `BOLL_EXTRAWIDE_SCALE` | 1.2 | BOLL 极端宽判定比例因子：`bbw >= bbw_pctl × 该值` |
| `SAR_CHECK` | 0 | 买入 SAR 过滤开关：`1`=除 SAR 策略外，买入需 `SAR < close`；`0`=不检查 |
| `EMA60_CHECK` | 0 | BOLL 买入 EMA60 过滤开关：`1`=买入需 `EMA60 < close`；`0`=不检查 |
| `ADX_CHECK` | 0 | BOLL 买入 ADX 过滤开关：`1`=买入需 `ADX > 20`；`0`=不检查 |
| `INDEX_CHECK` | 0 | 全局买入指数过滤：`0`=不检查；`1`=上证指数收盘 > 指数 MA5；`2`=指数 MA5 或个股 MA5 |

- 生效策略：MA1030 / EMA1030 / MACD1226 / BOLL / MA310 / MA520 / EMA520（以及历史 `RSIStrategy`）。
  `BOLL_SQUEEZE_SCALE` / `BOLL_EXTRAWIDE_SCALE` / `bbw_lookback` 当前不生效（BOLL 带宽过滤已停用）。
- 构造参数显式传入时以传入值为准；传 `None` 表示禁用该过滤（如显式传 `max_drawdown=None` 禁用回撤止损）。
- 加载结果在进程内缓存，修改配置后需重新启动进程生效。

## 一、技术指标类策略

### 1.1 MA1030 策略 (MACrossStrategy)

**定位：** 经典趋势跟踪，适用于有明显趋势的市场。

**因子（指标）选择**

| 指标 | 周期 | 说明 |
|------|:---:|------|
| 快线 `fast_ma` | 10 | 短期 SMA，反映近期价格 |
| 慢线 `slow_ma` | 30 | 中期 SMA，反映趋势方向 |
| RSI | 14 | 相对强弱，用于买卖过滤 |

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | 金叉（`fast_ma.shift(1) <= slow_ma.shift(1)` 且 `fast_ma > slow_ma`）且 `RSI < MIN_RSI_THRESHOLD` | 金叉 + 未过热 |
| 卖出 `-1` | 死叉（`fast_ma.shift(1) >= slow_ma.shift(1)` 且 `fast_ma < slow_ma`）**或** `RSI > MAX_RSI_THRESHOLD` | 死叉或 RSI 超买 |
| 观望 `0` | 其余 | — |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `fast_period` | 10 | 快线周期 |
| `slow_period` | 30 | 慢线周期 |
| `rsi_buy_max` | 配置 `MIN_RSI_THRESHOLD` | 买入附加条件 `RSI < MIN_RSI_THRESHOLD`（`None` 不启用） |
| `rsi_sell_min` | 配置 `MAX_RSI_THRESHOLD` | 卖出附加条件 `RSI > MAX_RSI_THRESHOLD`（`None` 不启用） |

**设计要点：** 用 `shift(1)` 检测交叉的"边沿"而非"状态"，仅在交叉发生当日出信号，其余交易日保持观望，避免重复信号。买入附加 `RSI < MIN_RSI_THRESHOLD`，以过滤过热追高。**本策略不区分增强级别**（`-gN` 对其无额外处理）。ETF 版参数为 MA10/MA40。

### 1.2 EMA1030 策略 (EMACrossStrategy)

**定位：** 与 ma1030 类似，仅将快慢均线由 SMA 换成 EMA（指数移动平均）。EMA 对近期价格赋予更高权重、反应更快。

**因子（指标）选择**

| 指标 | 周期 | 说明 |
|------|:---:|------|
| 快线 `fast_ema` | 10 | 短期 EMA，反映近期价格 |
| 慢线 `slow_ema` | 30 | 中期 EMA，反映趋势方向 |
| RSI | 14 | 相对强弱，用于买卖过滤 |

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | 金叉（`fast_ema.shift(1) <= slow_ema.shift(1)` 且 `fast_ema > slow_ema`）且 `RSI < MIN_RSI_THRESHOLD` | 金叉 + 未过热 |
| 卖出 `-1` | 死叉（`fast_ema.shift(1) >= slow_ema.shift(1)` 且 `fast_ema < slow_ema`）**或** `RSI > MAX_RSI_THRESHOLD` | 死叉或 RSI 超买 |
| 观望 `0` | 其余 | — |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `fast_period` | 10 | 快线周期 |
| `slow_period` | 30 | 慢线周期 |
| `rsi_buy_max` | 配置 `MIN_RSI_THRESHOLD` | 买入附加条件 `RSI < MIN_RSI_THRESHOLD` |
| `rsi_sell_min` | 配置 `MAX_RSI_THRESHOLD` | 卖出附加条件 `RSI > MAX_RSI_THRESHOLD` |

> RSI 条件作用于金叉/死叉定义本身，因此增强级别 1 亦继承该过滤。

**增强级别 1（`ema10301`）**

在基础交叉基础上增加短期均线（快线）斜率确认（`slope(快线) = fast_ema.diff()`）。
仅满足基础金叉/死叉出买/卖信号（`±1`）；增强级别叠加过滤条件，仅触发满足全部条件的信号：

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买 `1` | 金叉（快线上穿慢线） | 基础版条件 |
| 买 `1` | 金叉 且 `slope(快线) > 0` | 金叉 + 短期均线向上 |
| 卖 `-1` | 死叉（快线下穿慢线） | 基础版条件 |
| 卖 `-1` | 死叉 且 `slope(快线) < 0` | 死叉 + 短期均线向下 |

> 通过 `-g1 ema1030` 或 `-g ema10301` 启用。

### 1.3 MACD1226 策略 (MACDStrategy)

**定位：** 趋势跟踪动量策略，通过快慢 EMA 差值反映趋势强度与方向变化。

**因子（指标）选择**

| 指标 | 计算 | 说明 |
|------|------|------|
| DIF | EMA12 - EMA26 | 快慢线差，动量核心 |
| DEA | DIF 的 9 日 EMA | 信号线 |
| MACD 柱 | 2 × (DIF - DEA) | 动能强弱 |
| RSI | 14 | 相对强弱，用于买卖过滤 |

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | `DIF.shift(1) <= DEA.shift(1)` 且 `DIF > DEA` 且 `RSI < MIN_RSI_THRESHOLD` | 金叉 + 未过热 |
| 卖出 `-1` | 死叉（`DIF.shift(1) >= DEA.shift(1)` 且 `DIF < DEA`）**或** `RSI > MAX_RSI_THRESHOLD`；**或** 买入后自最高收盘价回撤 ≥ `MAX_DRAWDWON_THRESHOLD` | 死叉/RSI 超买或回撤止损 |
| 观望 `0` | 其余 | — |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `fast` | 12 | 快速 EMA 周期 |
| `slow` | 26 | 慢速 EMA 周期 |
| `signal` | 9 | DEA 信号线周期 |
| `rsi_buy_max` | 配置 `MIN_RSI_THRESHOLD` | 买入附加条件 `RSI < MIN_RSI_THRESHOLD`（`None` 不启用） |
| `rsi_sell_min` | 配置 `MAX_RSI_THRESHOLD` | 卖出附加条件 `RSI > MAX_RSI_THRESHOLD`（`None` 不启用） |
| `max_drawdown` | 配置 `MAX_DRAWDWON_THRESHOLD` / 100 | 买入后自最高收盘价回撤 ≥ 阈值止损卖出（`None` 不启用） |
| `ma_period` | 20 | 增强过滤用趋势快速均线周期 |
| `ma_slow` | 60 | 增强过滤用趋势慢速均线周期 |

**设计要点：** 金叉时 `DIF > DEA` 恒成立，故 `MACD柱 > 0` 为冗余条件已省略；买卖附加 RSI 过滤（`RSI<MIN_RSI_THRESHOLD` / `RSI>MAX_RSI_THRESHOLD`）以抑制过热追高与提前离场。RSI 已并入金叉/死叉定义，增强级别同样继承。买入后逐日跟踪最高收盘价，回撤达到 `MAX_DRAWDWON_THRESHOLD` 时优先卖出。

**增强级别 1（`macd12261`）** — 金叉/死叉 + 次日延续确认

`MA60 = 60 日均线`，`vol_ma20 = 20 日均量`，`ret = 当日涨跌幅`。（强弱已合并，均为 买 `1` / 卖 `-1`）

| 方向 | 条件（满足任一即触发） |
|:---:|---|
| 买 `1` | 金叉 |
| 买 `1` | 金叉次日：`close>MA60` 且 `vol>vol_ma20` 且 `ret<3%`；或昨日为买 且 `ret<3%` |
| 卖 `-1` | 死叉 |
| 卖 `-1` | 死叉次日：`close<MA60` 且 `vol>vol_ma20` 且 `ret<3%`；或昨日为卖 且 `ret<3%` |

> 通过 `-g1 macd1226` 或 `-g macd12261` 启用（需 df 含 `volume` 列）。

### 1.5 KDJ 策略 (KDJStrategy)

**定位：** 随机振荡指标（KDJ），比较收盘价在近期高低价区间中的位置，捕捉低位金叉/高位死叉的超买超卖反转。

**因子（指标）选择**

| 指标 | 周期 | 说明 |
|------|:---:|------|
| K | n=9, m1=3 | RSV 的平滑线 |
| D | m2=3 | K 的平滑线 |
| J | — | 3K - 2D，反映偏离度 |
| MA60 | 60 | 买入过滤（站上 60 日线） |

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | `K.shift(1) <= D.shift(1)` 且 `K > D` 且 `close > MA60` | 金叉 + 站上 60 日线 |
| 卖出 `-1` | `K.shift(1) >= D.shift(1)` 且 `K < D` | 死叉：K 下穿 D |
| 观望 `0` | 其余 | — |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `n` | 9 | RSV 计算周期 |
| `m1` | 3 | K 线平滑周期 |
| `m2` | 3 | D 线平滑周期 |
| `oversold` | 20 | 超卖阈值（K 低于此值视为超卖） |
| `overbought` | 80 | 超买阈值（K 高于此值视为超买） |
| `ma_slow` | 60 | 买入过滤用慢速均线（MA60）周期 |

**设计要点：** 基础买卖判定（交叉边沿 + `close>MA60` 过滤）即为最终逻辑，**本策略不区分增强级别**（`-gN` 不再产生额外过滤）。依赖 `high`/`low`/`close` 三列。

### 1.6 布林带策略 (BollingerStrategy)

**定位：** 利用布林带上下轨作为支撑/阻力位的均值回归反转策略。

**因子（指标）选择**

| 指标 | 计算 | 说明 |
|------|------|------|
| 中轨 MIDDLE | 20 日 SMA | 趋势基准 |
| 上轨 UPPER | 中轨 + 2σ | 阻力位 |
| 下轨 LOWER | 中轨 - 2σ | 支撑位 |
| RSI | 14 | 买入/卖出过滤 |

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | 下轨反弹（`close.shift(1) <= lower.shift(1)` 且 `close > lower`）**且** `RSI < MIN_RSI_THRESHOLD`；`EMA60_CHECK=1` 时**且** `EMA60 < close`；`ADX_CHECK=1` 时**且** `ADX > 20` | 低位反弹 + 未过热（带宽过滤已停用） |
| 卖出 `-1` | 上轨回落（`close.shift(1) >= upper.shift(1)` 且 `close < upper`）**或** `RSI > MAX_RSI_THRESHOLD`；**或** 买入后自最高收盘价回撤 ≥ `MAX_DRAWDWON_THRESHOLD` | 上轨回落/RSI 超买或回撤止损（不受带宽过滤影响） |
| 观望 `0` | 其余 | — |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `period` | 20 | 中轨周期 |
| `std` | 2 | 标准差倍数 |
| `bbw_lookback` | 10 | 带宽过滤统计回看窗口（当前过滤已停用） |
| `max_drawdown` | 配置 `MAX_DRAWDWON_THRESHOLD` / 100 | 买入后自最高收盘价回撤 ≥ 阈值止损卖出 |
| `BOLL_SQUEEZE_SCALE` | 配置（默认 0.2） | 挤压判定比例因子（当前过滤已停用） |
| `BOLL_EXTRAWIDE_SCALE` | 配置（默认 1.2） | 极端宽判定比例因子（当前过滤已停用） |
| `EMA60_CHECK` | 配置（默认 0） | 1=买入要求 `EMA60 < close`；0=不检查 |
| `ADX_CHECK` | 配置（默认 0） | 1=买入要求 `ADX > 20`；0=不检查 |

**设计要点：** 采用"穿越轨道边沿"判定，捕捉价格回到带内的反转时刻。原布林带宽度过滤（非挤压 / 非极端宽）经实测效果不佳，已**停用**（代码保留、过滤行注释），当前逻辑：

- 买入：下轨反弹 **且** `RSI < MIN_RSI_THRESHOLD`（`EMA60_CHECK=1` 时另加 `EMA60 < close`；`ADX_CHECK=1` 时另加 `ADX > 20`）；
- 卖出：上轨回落 **或** `RSI > MAX_RSI_THRESHOLD`，或回撤止损；
- `bbw_lookback` / `BOLL_SQUEEZE_SCALE` / `BOLL_EXTRAWIDE_SCALE` 当前不生效。

**BOLL 不再区分增强级别**（`-g1 boll` 或 `boll1` 与基础 `boll` 行为一致）。

### 1.7 MA310 策略 (SG1Strategy)

### 1.10 SAR 策略 (SARStrategy)

**定位：** 抛物线转向指标（Parabolic SAR），通过 SAR 与收盘价的位置切换判断趋势反转。

**指标计算：** 标准 Parabolic SAR，加速因子初始 `0.02`、步长 `0.02`、上限 `0.2`；逐日按极点价（EP）与加速因子（AF）递推，趋势反转时 SAR 跳至上一轮极点价另一侧。

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | 上一日 `SAR > close` 且当日 `SAR < close` | SAR 从 K 线上方突破至下方 |
| 卖出 `-1` | 上一日 `SAR < close` 且当日 `SAR > close` | SAR 从 K 线下方突破至上方 |
| 观望 `0` | 其余 | — |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `af_step` | 0.02 | 加速因子步长 |
| `af_max` | 0.2 | 加速因子上限 |

**设计要点：** 仅使用 SAR 与收盘价的穿越方向，不附加 RSI 过滤；**本策略不区分增强级别**（`-gN` 与基础 `sar` 行为一致）。`SAR_CHECK` 宏不作用于本策略。依赖 `high`/`low`/`close` 三列。

## 二、多因子类策略

### 2.1 质价融合策略 (QualityValueFactorStrategy)

**定位：** 融合估值、质量、筹码、增减持、波动率五个维度，加权生成综合投资价值评分并转换为买卖信号。是唯一依赖基本面/另类数据的多因子策略（详见 `doc/factor_design.md`）。

**因子选择（五个维度）**

| 维度 | 权重 | 因子 | 子权重 | 方向 |
|------|:---:|------|:---:|------|
| 估值（价值） | 0.35 | 见下方分型 | 见下方 | 见下方 |
| 质量 | 0.30 | ROE / 现金流质量 / 净利率 / 资产负债率 / 利润增长 | 0.30/0.25/0.20/0.15/0.10 | +/+/+/-/+ |
| 筹码（股东人数） | 0.15 | 股东人数变化 / 人均持股变化 | 0.6/0.4 | 减少好 / 增加好 |
| 增减持 | 0.10 | 近 12 个月累计净增持量 | 1.0 | 增持好 |
| 波动率（低波异象） | 0.10 | HV20 / MaxDD(250) / ATR14/close | 0.40/0.35/0.25 | 越低越好 |

**估值因子分型**

| 标的类型 | 判别 | 因子 | 子权重 |
|------|------|------|:---:|
| broad_index | 宽基指数代码 / ETF | pe_ttm, pb | [0.55, 0.45] |
| growth | 300/301/688 开头 | ps, pcf | [0.55, 0.45] |
| dividend | 默认 | pe_ttm, pb, ps | [0.40, 0.35, 0.25] |

**打分方式：** 各维度分别做分位数打分（估值逐日 / 质量按报告期 + ffill / 筹码按报告期 + ffill / 增减持按公告日 + ffill / 波动率逐日），得分均归一化到 0~1；再按有效维度权重动态归一化加权求和。

**滚动 Z-score 标准化：** 综合得分 combined 集中在小区间（如 0.4~0.7），直接阈值判断容易误判。因此先对 combined 轻度平滑（`rolling(3).mean()`），再做滚动 Z-score 标准化（窗口 20），用 Z 值阈值判定信号：

```
combined_smooth = combined.rolling(3).mean()
z_t = (combined_smooth,t - μ_window) / σ_window
```

**买卖信号生成（基于 Z 值）**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买 `1` | `z >= z_buy (1.0)` | 综合评估显著优于常态 |
| 卖 `-1` | `z <= z_sell (-1.0)` | 综合评估显著劣于常态 |
| 观望 `0` | `-1.0 < z < 1.0` | 中性 |

**增强级别 1（`quality_value1`）**

采用更严格 Z 值阈值：基础 `z >= 1.0` 买 / `z <= -1.0` 卖；增强级 `z >= 2.0` 买 / `z <= -2.0` 卖（强弱已合并为 买 `1` / 卖 `-1`）。

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买 `1` | `1.0 <= z < 2.0` | 仅满足基础阈值 |
| 买 `1` | `z >= z_strong_buy (2.0)` | 满足增强阈值 |
| 卖 `-1` | `-2.0 < z <= -1.0` | 仅满足基础阈值 |
| 卖 `-1` | `z <= z_strong_sell (-2.0)` | 满足增强阈值 |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `score_smooth_window` | 3 | 综合得分轻度平滑窗口 |
| `score_z_window` | 20 | 滚动 Z-score 窗口 |
| `z_buy` | 1.0 | 基础买入 Z 阈值 |
| `z_sell` | -1.0 | 基础卖出 Z 阈值 |
| `z_strong_buy` | 2.0 | 增强级买入 Z 阈值 |
| `z_strong_sell` | -2.0 | 增强级卖出 Z 阈值 |
| `value_weight` | 0.35 | 估值维度权重 |
| `quality_weight` | 0.30 | 质量维度权重 |
| `shareholder_weight` | 0.15 | 筹码维度权重 |
| `insider_weight` | 0.10 | 增减持维度权重 |
| `volatility_weight` | 0.10 | 波动率维度权重 |

**设计要点：** 单维度数据缺失时按剩余有效维度权重比例重新归一化，宽基指数自动跳过筹码/增减持维度；全部维度缺失时返回全 0 信号。`combined_score`、`z_score`、`z_buy`/`z_sell` 写入 `signals.attrs` 供图表展示（质价子图显示「综合得分Z」曲线与 ±阈值参考线）。

### 3.2 买入并持有策略 (HoldStrategy)

**定位：** 基准对照策略，用于衡量其它策略相对"买入持有"的超额收益。

- 信号：从分析期 start 起全部买入（`1`）并持有到分析期结束（`warmup=0`），无任何卖出信号
- 回测结果（fraction 模式）：1 次买入、0 次卖出，权益曲线即纯买入持有表现
- 参数：`warmup=0`（预热天数，信号从 start 起即可考虑）

---

### 3.3 PREV 策略（analyze 自动追加，非 `-g` 可选）

**定位：** 对 `-g` 所选策略**上一交易日**的信号做多数表决，作为"隔日确认"的合成信号。

**规则：** 对每个交易日 `t`，统计所选策略（排除 `hold`，也不考虑前一日 PREV 自身）在 `t-1` 日的信号：

| 情形 | PREV 信号 |
|:---:|:---:|
| 买入信号数 > 卖出信号数 | 买 `1` |
| 买入信号数 = 卖出信号数 | 观望 `0` |
| 买入信号数 < 卖出信号数 | 卖 `-1` |

- 首个交易日无前一交易日，记为观望 `0`。
- 信号实现为：将各所选策略信号按日期 `shift(1)`，逐日比较 `>0`（买）与 `<0`（卖）的数量。
- 显示名 `PREV`（key `prev`）；`analyze` 会对其照常做回测、纳入策略对比排名、最新信号表、HTML 报告与钉钉通知。
- 仅 `analyze` 命令自动追加；`scan`/`backtest`/`compare` 不含。

---

### 3.4 复合策略（backtest 自动追加，首个买入策略跟随）

**定位：** `backtest` 命令在 `-g` 所选策略之外自动追加的"复合策略"（key `combo`，显示名 `复合策略`），
"跟随首个买入策略"的组合效果。**注意**：与已移除的加权投票综合策略（`composite`）不同。

**规则（逐日状态机）：**

| 状态 | 条件 | 复合策略信号 |
|:---:|:---:|:---:|
| 空仓 | 所选策略中**任一**当日出现买入(`>0`) | 买 `1` → 转为持仓，并**记住**该买入策略 |
| 持仓 | **仅当被记住的那个策略**当日出现卖出(`<0`) | 卖 `-1` → 转为空仓 |
| 其它 | — | 观望 `0` |

- 空仓时同一天多只策略买入，按所选顺序记住**第一个**买入的策略。
- 持仓期间其它策略的卖出信号不影响复合策略（只等被记住策略的卖出）。
- 不考虑 PREV 与 Hold 策略的信号（`hold` 被排除）。
- 无有效来源策略时，复合策略不追加。
- 仅 `backtest` 命令自动追加（单股多策略与批量回测均适用）；`analyze` 用 PREV、`scan`/`compare` 不含合成策略。

## 四、指数专属策略

> 通过 `-i/--index` 参数启用，适用于大盘指数分析。

### 4.1 动量分层策略 (MomentumTieredStrategy)

**定位：** 指数动量效应显著（强者恒强），采用"动量 + 趋势"双因子共振。

**因子（指标）选择**

| 指标 | 周期 | 说明 |
|------|:---:|------|
| 动量收益 | 60 日 | 过去 60 日累计收益率，正值表示向上动量 |
| MA20 | 20 | 快速均线（趋势确认） |
| MA60 | 60 | 慢速均线（趋势确认） |

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | `momentum > 0` 且 `MA20 > MA60` | 动量 + 趋势共振（多头排列） |
| 卖出 `-1` | `momentum < 0` | 动量转负（趋势衰竭，无论均线） |
| 观望 `0` | 其余 | 含"有反弹动能但趋势未转多"的抄底陷阱 |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `momentum_period` | 60 | 动量回看周期 |
| `ma_fast` | 20 | 快速均线 |
| `ma_slow` | 60 | 慢速均线 |

---

### 4.2 波动率择时策略 (VolatilityTimingStrategy)

**定位：** 利用指数波动率均值回归特性：低波动突破胜率高，高波动下跌风险大。

**因子（指标）选择**

| 指标 | 周期/阈值 | 说明 |
|------|:---:|------|
| 年化历史波动率 HV | 20 日 | 低波动 < 15%，高波动 > 30% |
| 布林上轨 | 20 日 / 1.5σ | 窄带（适配指数，窄于个股 2.0） |
| MA20 | 20 | 卖出防线 |

**买卖信号生成**

| 信号 | 条件 | 说明 |
|:---:|---|---|
| 买入 `1` | `HV.shift(1) < 0.15` 且 `HV < 0.15` 且 `close > 布林上轨` | 持续低波动 + 向上突破 |
| 卖出 `-1` | `HV > 0.30` 且 `close < MA20` | 高波动 + 跌破均线 |
| 观望 `0` | 其余 | — |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `vol_period` | 20 | 波动率周期 |
| `vol_low` | 0.15 | 低波动阈值（年化） |
| `vol_high` | 0.30 | 高波动阈值（年化） |
| `bb_period` | 20 | 布林带周期 |
| `bb_std` | 1.5 | 布林带标准差倍数 |
| `ma_period` | 20 | 卖出均线周期 |

**设计要点：** 买入用 `HV.shift(1)` 与 `HV` 双期同时 < 阈值，确认低波动是"持续状态"而非"刚进入"，避免单日波动率骤降的误判。

### 4.3 涨跌比确认策略 (BreadthConfirmationStrategy)

**定位：** 市场宽度（涨跌家数比）是市场健康的"体检报告"，比指数更早转向；涨跌比与价格趋势共振时出信号。

**因子（指标）选择**

| 模式 | 因子 | 阈值 | 说明 |
|------|------|:---:|------|
| 主模式 | 涨跌比（上涨家数/下跌家数） | >2.0 / <0.5 | 市场宽度 |
| 主模式 | MA5 | — | 价格确认 |
| 降级模式 | 量比（当日量/5日均量） | >1.5 / <0.6 | 参与度代理 |

**买卖信号生成**

| 信号 | 模式 | 条件 |
|:---:|---|---|
| 买入 `1` | 主 | 涨跌比 > 2.0 且 `close > MA5` |
| 卖出 `-1` | 主 | 涨跌比 < 0.5 且 `close < MA5` |
| 买入 `1` | 降级 | 量比 > 1.5 且 `close > MA5`（放量上涨） |
| 卖出 `-1` | 降级 | 量比 < 0.6 且 `close < MA5`（缩量下跌） |
| 观望 `0` | 任一 | 其余 |

**参数**

| 参数 | 默认 | 说明 |
|------|:---:|------|
| `breadth_high` | 2.0 | 涨跌比买入阈值 |
| `breadth_low` | 0.5 | 涨跌比卖出阈值 |
| `ma_period` | 5 | 价格确认均线周期 |
| `vol_ratio_threshold` | 1.5 | 量比阈值（降级模式） |

**设计要点：** `generate_signals(df, breadth_data=None)` 接收可选的涨跌比序列；无涨跌比数据时自动降级为成交量比模式，保证策略始终可运行。

**增强级别（`-g[N]`）：**

通过 `-gN`（如 `-g1 macd1226` 即 `macd12261`）或单策略后缀（`-g macd12261`）启用，
在基础信号判定上叠加额外过滤条件（信号均为 买 `1` / 卖 `-1`，强弱不再区分）：

| 增强策略 | 附加过滤 |
|------|------|
| `ema10301` | 金叉/死叉 + 快线斜率确认（`slope>0`/`<0`）（含基础 RSI 过滤） |
| `macd12261` | 金叉/死叉 + 次日延续确认（MA60/放量）（含基础 RSI 过滤） |
| `quality_value1` | 更严格 Z 阈值：`z >= 2.0` 买、`z <= -2.0` 卖 |

> `ma1030`、`boll`、`ma310`、`ma520`、`ema520`、`kdj`、`sar` 均无增强级别（BOLL 的带宽过滤已停用，
> `boll1` 与 `boll` 行为一致）；`ma310`/`ma520`/`ema520` 的买入条件为
> 金叉 + 当日跌幅不超过 1% + `RSI < MIN_RSI_THRESHOLD`，涨幅上限由全局买入条件（< 9.9%）统一控制。

**次日信号预测（`--forecast`）：**

当日信号为观望时，用二分法（±10% 区间、5 次递归）模拟次日收盘价，求出触发买入/卖出的**涨跌百分比阈值**，如 `卖≤1.9`（次日较今日收盘下跌 ≤1.9% 触发卖出）、`买≥6.3`。预测同样受全局买入条件约束（次日涨幅 ≥ 9.9% 不会触发买入）。

**共通约定：**

1. 所有技术指标类策略用 `shift(1)` 检测"交叉/穿越边沿"，仅在触发当日出信号，其余为观望。
2. 所有策略信号序列索引与行情 `df.index` 严格对齐，值为 `1/-1/0`。
3. 除质价融合与涨跌比确认外，其余策略仅依赖 `close`（及可选 `volume`），无外部数据依赖；RSI 过滤优先取 `RSI14`，缺失时按 `close` 用 `calc_rsi` 现算。
4. **全局买入附加条件**：所有策略（及 PREV/复合策略等派生信号）在信号生成后统一过滤「当日涨幅 ≥ 9.9%」的买入信号（`_filter_buy_on_big_gain`），卖出/观望不受影响。`SAR_CHECK=1` 时另加「当日 SAR < close」买入条件（SAR 策略本身除外）；`EMA60_CHECK=1` 时 BOLL 另加「当日 EMA60 < close」买入条件；`ADX_CHECK=1` 时 BOLL 另加「当日 ADX > 20」买入条件；`INDEX_CHECK=1` 时所有策略另加「上证指数收盘 > 上证指数 5 日均线」买入条件；`INDEX_CHECK=2` 时改为「指数收盘 > 指数 MA5 或 个股收盘 > 个股 MA5」。
