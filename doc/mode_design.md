# 分析模式设计 (-m)

本文档说明 `main.py` 的 `analyze` 命令中 `-m/--mode` 参数不同取值下的买卖策略，包括**选股策略**与**买卖行为策略**。

## 1. 模式总览

| mode | 名称 | 持仓方式 | 核心思想 |
|------|------|----------|----------|
| 0 | 常规综合分析 | 单标的独立 | 对每只股票跑所有策略并排名，不做跨股资金分配 |
| 1 | 资金利用最大化轮动选股 | 集中持仓（支持单只） | 买入信号出现时全仓买入，现金不足且持仓涨超 1/3 时卖半轮动 |
| 2 | 多持仓资金利用最大化 | 多持仓 | 现金优先买入（单只≤1/3），不足则卖走弱持仓腾资金 |
| 3 | 多持仓强化优化 | 多持仓 | 在模式 2 基础上引入趋势判断，现金不足且买入股弱势时取消被动卖出与买入 |
| 4 | 多持仓强化优化（趋势择股卖出） | 多持仓 | 在模式 3 基础上，被动卖出仅在弱势/横盘震荡间择股，取消强势股卖出 |

## 2. 共用的信号基础

### 2.1 信号语义

所有策略通过 `generate_signals(df)` 输出与行情索引对齐的 `pd.Series`：

- `1`：买入
- `-1`：卖出
- `0`：持有（不操作）

### 2.2 策略注册表

- `STRATEGY_MAP`：个股策略（`ma_cross`、`ema_cross`、`macd`、`rsi`、`bollinger`、`kdj`、`quality_value`、`composite`）
- `INDEX_STRATEGY_MAP`：指数专属策略（`momentum`、`volatility`、`breadth`）
- `ETF_STRATEGY_MAP`：ETF/指数基金专用策略（参数适配低波动、趋势跟随）
- `composite` 综合策略：参与加权的子策略与权重由 `input/stock-quant.json` 的 `composite` 配置决定；
  每个子策略的参与加权原始值 = 信号值 × 0.7 + 仓位水平 × 0.3，加权求和后先轻度平滑
  （rolling(3).mean()）再做滚动 Z-score 标准化（窗口 20），按 `z>1.0` 买入 / `z<-1.0` 卖出生成信号。

### 2.3 数据与指标

- 行情：`DataFetcher.get_stock_data(symbol, start_date, end_date)`
- 指标：`add_all_indicators(df)`，产出 MA5/10/20/60/120、MACD（DIF/DEA/BAR）、RSI、BOLL、KDJ、ATR、ADX/+DI/-DI、OBV、CCI、WR、VWAP、HV、MOM 等
- 其中 `MACD_BAR` 用于被动卖出判断，`ADX14`/`PLUS_DI`/`MINUS_DI`/`MA120` 用于趋势判断

### 2.5 个股趋势判断

`classify_trend(df, date)` 将个股当前趋势分为三类，`date` 用于回测时只取 ≤ 该日期的数据（避免未来函数）。

**强势（多头趋势）—— 全部满足：**

1. 均线多头排列：`MA20 > MA60 > MA120`
2. `ADX(14) ≥ 25`（趋势强度足够）
3. `+DI > -DI`（多头方向占优）
4. 最近 60 日价格线性回归斜率 `> 0`
5. MACD 辅助：`DIF > 0`

**弱势（空头趋势）—— 全部满足：**

1. 均线空头排列：`MA20 < MA60 < MA120`
2. `ADX(14) ≥ 25`
3. `-DI > +DI`
4. 60 日价格回归斜率 `< 0`
5. MACD 辅助：`DIF < 0`

**横盘震荡（无趋势）—— 满足任意两条：**

1. `ADX(14) < 25`（最核心，趋势很弱）
2. `|MA20 - MA60| / MA60 < 0.03`（均线缠绕）
3. 60 日价格线性回归归一化斜率绝对值 `< 0.001`（接近 0）
4. `60 日最高价 / 60 日最低价 < 1.3`（振幅不大，箱体运行）

## 3. 模式 0：常规综合分析（默认）

### 选股策略

股票池来源（可组合、去重合并）：

- `-s`：直接指定代码/名称，支持多只（空格分隔）与通配符（如 `60*`）
- `-sf`：从 JSON 文件读取自选股列表
- `-h N`：按 HotScore 热度分排序取前 N 只热门股
- 均未指定时：读 `stock-quant.json` 的 `favorites`，否则读 `input/favs.json`

### 买卖行为

对每只股票分别运行各策略（`_run_single_analysis`）：

1. `strategy.generate_signals(df)` 生成信号（`±0.5` 弱 / `±1.0` 强 / `0`）
2. `BacktestEngine.run(df, signals, position_style='fraction')` 按信号比例回测（CLI 所有入口均用 fraction）：
   - 仓位水平 `in_position` 为 0~1 浮点数：弱买 `+0.5` / 强买 `+1` 累加（封顶 1），弱卖 `-0.5` / 强卖 `-1` 递减（下限 0）
   - `in_position < 1` 时可买入，`> 0` 时可卖出；买入金额 = 当前现金 × 实际增量，卖出比例 = 递减量/当前水平
   - 买入/卖出执行次数分别统计（报告显示为「买入/卖出次数」）
3. 结果做风险分析、生成图表与 HTML 报告

### 特点

模式 0 不做跨股票的资金分配，是**单标的、多策略**的对比分析与排名（按总收益率/夏普等排序）。

## 4. 模式 1：资金利用最大化轮动选股

### 选股策略

- 股票池来自 `-s`/`-sf`/`-h`（要求 **≥1 只**，单只作为特例处理）
- 策略：`-g all` → ma_cross，否则取 `|` 分隔列表的**第一个**策略
- 每日遍历股票池，对出现买入信号(`>0`)的股票**用全部剩余资金买入**（已持有的不重复买入）

### 买卖行为（集中持仓 + 部分止盈轮动）

每日（按股票池交易日**并集**排序后逐日处理）：

1. **卖出检查**：持仓中当日信号 `< 0` 的股票 → 全部清仓
2. **买入检查**：遍历股票池，对出现买入信号(`>0`)的股票用**全部剩余资金**买入；**若有多个股票满足条件，只买入第一只符合条件的股票**
3. **资金不足处理**：若买入时剩余资金 `< 总资金 / 10`，且存在持仓权益 `> 总资金 / 3` 的股票，则**卖出该持仓的一半**释放资金（有多个时优先卖出权益最大者），再用全部剩余资金买入

### 特点

- 集中持仓：买入信号出现时全仓买入（不再限制单只 ≤ 1/3）
- 部分止盈：当持仓涨到占总资金 1/3 以上、且需腾出资金时，卖一半落袋，再轮动买入新信号
- 换股发生在持仓股出现卖出信号、或出现买入信号且现金不足触发部分止盈时
- **报告格式与模式 2/3/4 完全一致**（含「交易记录」「个股收益统计」「期末持仓」三张表）

## 5. 模式 2：多持仓资金利用最大化

### 选股策略

- 股票池来自 `-s`/`-sf`/`-h`（要求 **≥1 只**，1 只作为多只的特例处理）
- 策略：`-g all` → ma_cross，否则取第一个策略
- 每日按 `symbols` 顺序遍历股票池，找第一个买入信号(`>0`)的股票

### 买卖行为（多持仓、现金优先）

每日流程：

1. **步骤 0｜主动卖出**：遍历股票池，持仓中信号 `< 0` 的**全部清仓**，释放现金
2. **步骤 1｜找买入信号**：按顺序找第一个信号 `> 0` 的股票
3. **现金充足分支**：`现金 > 总资金 × 10%` → 买入（**单只买入不超过 1/3 总资金**）
4. **现金不足分支**：
   - 在持仓中筛选 `MACD_BAR` 今日 `< 昨日`（MACD 柱下降）的股票
   - 按 `entry_date` 最早者优先
   - 被动卖出动作：持仓市值 `> 总资金 × 20%` → **卖一半**；否则 **全卖**
   - 只有发生卖出释放资金后才买入，否则放弃当日买入
5. 记录交易事件（清仓股在卖出栏标注 `(清)`）

### 卖出判断依据

| 类型 | 触发条件 | 动作 |
|------|----------|------|
| 主动卖出 | 策略 `-1` 信号 | 全部清仓 |
| 被动卖出 | 现金 ≤ 10% 且持仓 MACD 柱下降 | 持仓市值 > 20% 卖一半，否则全卖 |

被动卖出不是策略的 `-1` 信号，而是用 `MACD_BAR` 今日 < 昨日判断持仓是否走弱，作为腾资金的依据。

**主动/被动卖出互斥规则**：若当日已发生主动卖出（有信号 `< 0` 的持仓被清仓），则**不再执行被动卖出**。

### 交易记录表

栏目顺序：日期、买入股票、买入资金、卖出股票、卖出资金、总权益、剩余资金、持股种类数。

- 卖出多只股票时以换行分隔展示
- 清仓（全部卖出）的股票在名称后标注 `(清)`

### 统计口径

- 个股收益：`总收益 = 卖出金额 + 期末市值 - 买入金额`
- 个股收益率：`收益率 = 总收益 / 持股期间日平均股票权益`（日平均权益 = 每日持仓市值之和 ÷ 持股天数）
- 期末持仓成本价：`(期末市值 - 总收益) / 期末市值 × 最新价`
- 概要信息：`闲置资金天数 = 分析周期内每日剩余资金累计（按日历日，非交易日沿用最近交易日）/ 资金总额`

## 6. 模式 3：多持仓强化优化

在模式 2 基础上，引入个股趋势判断作为买卖的考虑条件（`_run_portfolio_analysis_v3` 以 `weak_trend_cancel=True` 调用）：

- **现金不足分支**：若买入股当前趋势为**弱势**，则**取消被动卖出和买入**（放弃当日买入）；若买入股趋势非弱势，则按模式 2 正常执行被动卖出与买入

其余逻辑与模式 2 一致（含主动/被动卖出互斥规则、单只买入 ≤ 1/3 总资金）。

## 7. 模式 4：多持仓强化优化（趋势择股卖出）

在模式 3 基础上，修改**被动卖出的选股方式**（`_run_portfolio_analysis_v4` 以 `weak_trend_cancel=True, trend_priority_sell=True` 调用）：

- 当多个持仓同时满足卖出条件（MACD 柱下降）时，不再简单选最早买入者，而是**比较个股趋势值**，优先级：**弱势 > 横盘震荡**（**取消强势股卖出**，强势股不参与被动卖出）
- 同一趋势优先级内，仍按 `entry_date` 最早者优先

其余逻辑与模式 3 一致。

| 维度 | mode 0 | mode 1 | mode 2 | mode 3 | mode 4 |

| 卖出触发 | 各策略自身信号 | `-1` 信号 + 现金不足时部分止盈 | `-1` 信号 + MACD 柱下降 | `-1` 信号 + MACD 柱下降 | `-1` 信号 + MACD 柱下降 |

## 9. 报告通用标注

各模式的 HTML 报告概要信息中均标注**命令参数**（`_format_cmd_params` 生成的 `analyze ...` 摘要），记录本次运行所用的全部选项参数（`-s`/`-sf`/`-h`/`-st`/`-e`/`-g`/`-i`/`-c`/`-o`/`-of`/`-t`/`-db`/`-m`），便于复现。

### 报告概要额外指标

- **模式 1~4**：概要区块额外输出**夏普比率**与**最大回撤**（由回测期间的每日权益曲线计算：`夏普 = 日均超额收益 / 日收益标准差 × √252`，`最大回撤 = max((峰值-谷值)/峰值)`）。
- **模式 0**：各策略的排名表/详情表已含夏普比率、最大回撤等风险指标，概要区块不再重复。

### 报告文件名规则

统一格式：`source_yyyymmdd_daysd_strategy_mode_profit.html`

| 字段 | 含义 | 示例 |
|------|------|------|
| `source` | 股票源：`-s` 指定的代码（多只为 `multi`），`-sf` 指定的文件名（去扩展名），`-h` 为 `hot<N>`，默认 `favs` | `000725`、`multi`、`big`、`hot5` |
| `yyyymmdd` | 结束日期（`-e` 或今天），格式 `yyyymmdd` | `20260816` |
| `daysd` | 分析周期天数（结束日期 - 起始日期的天数）+ `d` 后缀 | `180d` |
| `strategy` | `-g` 指定的策略（含 `\|` 时替换为 `_`） | `macd`、`all`、`macd_rsi` |
| `mode` | `-m` 取值，格式 `m<mode>` | `m0`、`m4` |
| `profit` | 收益率/平均收益率的百分数整数（如 67.5% → 67），无此项信息时省略 | `31`、`-13`、`0` |

各模式 `profit` 取值：

- 模式 0 单只：最佳策略的 `total_return`
- 模式 0 多只：各股票最佳策略收益率的均值（平均收益率）
- 模式 1~4：回测 `total_return`

示例：`000021_20260816_180d_macd_m0_31.html`、`multi_20260816_180d_all_m1.html`（无收益率时省略 profit 字段）

### 日期范围选项

`-st`/`-e` 指定分析区间（格式 `YYYYMMDD`）：未指定 `-st` 时默认结束日前 365 天，未指定 `-e` 时默认今天。

## 10. scan 命令（股票筛选）

- 股票列表获取：未指定 `-sf` 时通过新浪行情中心拉取全部 A 股（1000 只），可用排序选项控制获取顺序：
  - `--changepercent`（默认）：按涨跌幅降序
  - `--turnoverratio`：按换手率降序
  - `--amount`：按成交额降序
  - `--mktcap`：按总市值降序
  - `--pe`：按市盈率降序
- `--random`：拉取全部 A 股后按 **沪市主板:深市主板:创业板:科创板 = 6:5:5:2** 的比例**随机抽样** 20*N 只股票分析（按最大余数法分配各板块数量，忽略排序选项与 `-o` 偏移）。板块按代码前缀识别：沪市主板 `600/601/603/605`、深市主板 `000/001/002/003`、创业板 `300/301`、科创板 `688`。
- 指定 `-sf` 时直接从文件顺序读取股票代码（跳过 `-oN` 条后取前 `20*N` 只），不使用排序/随机选项。
- `-tN` 取前 N 只输出；`-oN` 跳过前 N 条；`--min-volume` 按成交量过滤（随机模式下先过滤再抽样）；`-xN` 并行进程数。
