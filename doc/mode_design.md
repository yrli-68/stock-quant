# 分析模式设计 (-m)

本文档说明 `main.py` 的 `analyze` 命令中 `-m/--mode` 参数不同取值下的买卖策略，包括**选股策略**与**买卖行为策略**。

## 1. 模式总览

| mode | 名称 | 持仓方式 | 核心思想 |
|------|------|----------|----------|
| 0 | 常规综合分析 | 单标的独立 | 对每只股票跑所有策略并排名，不做跨股资金分配 |
| 1 | 资金利用最大化轮动选股 | 单持仓 | 全仓持有最强信号股，信号切换即换股 |
| 2 | 多持仓资金利用最大化 | 多持仓 | 现金优先买入，不足则卖走弱持仓腾资金 |
| 3 | 多持仓强化优化 | 多持仓 | 在模式 2 基础上强化买卖信号与选股（迭代中） |

## 2. 共用的信号基础

### 2.1 信号语义

所有策略通过 `generate_signals(df)` 输出与行情索引对齐的 `pd.Series`：

- `1`：买入
- `-1`：卖出
- `0`：持有（不操作）

### 2.2 策略注册表

- `STRATEGY_MAP`：个股策略（`ma_cross`、`macd`、`enhanced_macd`、`rsi`、`bollinger`、`quality_value`、`composite`）
- `INDEX_STRATEGY_MAP`：指数专属策略（`momentum`、`volatility`、`breadth`）
- `ETF_STRATEGY_MAP`：ETF/指数基金专用策略（参数适配低波动、趋势跟随）
- 默认综合策略权重 `_DEFAULT_COMPOSITE_WEIGHTS` 与阈值 `_DEFAULT_COMPOSITE_THRESHOLD`（默认 0.25）

### 2.3 composite 综合策略

`CompositeStrategy.generate_signals` 采用**加权投票**机制：

1. 每个子策略独立生成信号
2. 按权重加权求和得到 `weighted_sum`
3. `weighted_sum > threshold` → 买入(1)；`< -threshold` → 卖出(-1)；其余 → 持有(0)

权重与阈值来自 `input/stock-quant.json` 的 `composite` 配置，缺失时回退到默认权重。

### 2.4 数据与指标

- 行情：`DataFetcher.get_stock_data(symbol, start_date, end_date)`
- 指标：`add_all_indicators(df)`，其中 `MACD_BAR` 列用于模式 2 的被动卖出判断

## 3. 模式 0：常规综合分析（默认）

### 选股策略

股票池来源（可组合、去重合并）：

- `-s`：直接指定代码/名称，支持多只（空格分隔）与通配符（如 `60*`）
- `-sf`：从 JSON 文件读取自选股列表
- `-h N`：按 HotScore 热度分排序取前 N 只热门股
- 均未指定时：读 `stock-quant.json` 的 `favorites`，否则读 `input/favs.json`

### 买卖行为

对每只股票分别运行各策略（`_run_single_analysis`）：

1. `strategy.generate_signals(df)` 生成信号
2. `BacktestEngine.run(df, signals)` 全仓回测（`position_style='full'`）
   - 信号 `1` 且空仓 → 全仓买入（扣佣金 0.0003、滑点 0.0001）
   - 信号 `-1` 且持仓 → 全仓卖出
3. 结果做风险分析、生成图表与 HTML 报告

### 特点

模式 0 不做跨股票的资金分配，是**单标的、多策略**的对比分析与排名（按总收益率/夏普等排序）。

## 4. 模式 1：资金利用最大化轮动选股

### 选股策略

- 股票池来自 `-s`/`-sf`/`-h`（要求 **≥2 只**）
- 策略：`-g all` → composite，否则取 `|` 分隔列表的**第一个**策略
- 每日按 `symbols` 顺序遍历股票池，买入**第一个**出现买入信号(1)的股票

### 买卖行为（单持仓、全仓进出）

每日（按股票池交易日**并集**排序后逐日处理）：

1. **卖出检查**：当前持仓股当日信号 `== -1` → 全部卖出，记录一段持仓期
2. **买入检查**：空仓时，按顺序找第一个信号 `== 1` 的股票 → 全额买入
3. **期末平仓**：回测结束仍持仓则强制平仓

### 特点

- 任一时刻最多持有 **1 只**股票
- 全仓进出，资金利用率 100%
- 换股只发生在持仓股出现卖出信号、且池内某股出现买入信号时

## 5. 模式 2：多持仓资金利用最大化

### 选股策略

- 股票池来自 `-s`/`-sf`/`-h`（要求 **≥1 只**，1 只作为多只的特例处理）
- 策略：`-g all` → composite，否则取第一个策略
- 每日按 `symbols` 顺序遍历股票池，找第一个买入信号(1)的股票

### 买卖行为（多持仓、现金优先）

每日流程：

1. **步骤 0｜卖出信号**：遍历股票池，持仓中信号 `== -1` 的**全部清仓**，释放现金
2. **步骤 1｜找买入信号**：按顺序找第一个信号 `== 1` 的股票
3. **现金充足分支**：`现金 > 总资金 × 10%` → 用剩余现金**全额买入**
4. **现金不足分支**：
   - 在持仓中筛选 `MACD_BAR` 今日 `< 昨日`（MACD 柱下降）的股票
   - 按 `entry_date` 最早者优先
   - 持仓市值 `< 总资金 × 50%` → **全卖**；否则 **卖一半**
   - 只有发生卖出释放资金后才买入，否则放弃当日买入
5. 记录交易事件（清仓股在卖出栏标注 `(清)`）

### 卖出判断依据

| 类型 | 触发条件 | 动作 |
|------|----------|------|
| 主动卖出 | 策略 `-1` 信号 | 全部清仓 |
| 被动卖出 | 现金 ≤ 10% 且持仓 MACD 柱下降 | 全卖（市值 < 50%）或卖一半（市值 ≥ 50%） |

被动卖出不是策略的 `-1` 信号，而是用 `MACD_BAR` 今日 < 昨日判断持仓是否走弱，作为腾资金的依据。

### 统计口径

- 个股收益：`总收益 = 卖出金额 + 期末市值 - 买入金额`
- 期末持仓成本价：`(期末市值 - 总收益) / 期末市值 × 最新价`

## 6. 模式 3：多持仓强化优化

在模式 2 基础上，进一步加强对**买卖信号**与**股票选择**的优化。当前复用模式 2 的基线逻辑（`_run_portfolio_analysis_v3` 委托 `_run_portfolio_analysis`），作为后续迭代的扩展点，不影响模式 2 的既有行为。

## 7. 对比总结

| 维度 | mode 0 | mode 1 | mode 2 | mode 3 |
|------|--------|--------|--------|--------|
| 定位 | 策略分析 | 轮动选股 | 多持仓 | 强化版多持仓 |
| 持仓数量 | 各策略独立单持仓 | 1 只 | 多只 | 多只 |
| 买入触发 | 各策略自身信号 | 池内第一个买入信号 | 池内第一个买入信号 | 待优化 |
| 卖出触发 | 各策略自身信号 | 持仓股 `-1` 信号 | `-1` 信号 + MACD 柱下降 | 待优化 |
| 仓位管理 | 全仓 | 全仓 | 现金优先 / 半仓 | 待优化 |
| 选股来源 | `-s`/`-sf`/`-h` | `-s`/`-sf`/`-h` | `-s`/`-sf`/`-h` | `-s`/`-sf`/`-h` |
| 报告前缀 | `{symbol}_` / `multi_` | `rotation_` | `portfolio_` | `portfolio_`（复用） |
